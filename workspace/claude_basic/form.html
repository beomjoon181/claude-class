text - 한 줄 텍스트 입력

password - 비밀번호 입력 (문자가 ●로 표시됨)

email - 이메일 형식 검증

number - 숫자만 입력

tel - 전화번호 입력

date - 날짜 선택

time - 시간 선택

checkbox - 여러 항목 중 다중 선택

radio - 여러 항목 중 하나만 선택

file - 파일 업로드

range - 슬라이더로 값 선택

color - 색상 선택

submit - 폼 제출 버튼

button - 일반 버튼 (동작은 JS로 지정)

hidden - 화면에 보이지 않는 값 전달
