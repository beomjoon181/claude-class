프로그래밍 패러다임
   - 개발자에게 프로그래머로서 관심을 갖게 하고 결정하는 역할(개발 방법)

패러다임의 종류
   1) 명령형
      - 절차 지향형 : 순서를 중요시하며 컴퓨터의 처리 구조와 비슷하게 개발, 
         속도가 빠르다(C, cobol, ...)
      - 객체 지향형 : 객체(집단) 상호 작용을 중요시하며 개발, 유지보수가 좋다(Java, C++)

   2) 선언형
      - 함수 지향형 : 순수 함수를 조합하고 프로그래밍하는 방법을 지향, 재사용성이 좋다(Javscript)

함수(function)란?
   - 코드 블록으로 감싸져 있는 문으로 이루어진 하나의 실행 단위

함수의 선언
   function 함수명(매개변수1, 매개변수2, ...){
      함수를 사용했을 때 실행할 문장
      필요시 return
   }

함수의 사용
   함수명()

return
   - 함수의 종료를 의미하며, return이 없다면 비즈니스 로직만 실행하고 값은 undefind
   return 키워드가 있다면 통째로를 return 값으로 보아야 한다   .

함수의 이름짓기
   - showMessage(..)     // 메시지를 보여줌
   - getAge(..)          // 나이를 나타내는 값을 얻고 그 값을 반환함
   - calcSum(..)         // 합계를 계산하고 그 결과를 반환함
   - createForm(..)      // form을 생성하고 만들어진 form을 반환함
   - checkPermission(..) // 승인 여부를 확인하고 true나 false를 반환함

함수의 규칙
   - 하나의 함수는 하나의 동작만 수행한다.
   - 함수는 이름에 언급 되어있는 동작을 반드시 수행해야 한다.
   - 언급된 기능외의 동작을 수행하면 안된다.

익명함수 : 이름이 없는 함수
   - 다른 함수의 매개 변수로 전달되어 바로 실행되는 함수
   - 매개변수, 콜백함수, 클로저, 즉시 실행 함수
   - 재사용성이 없는 경우에만 바로 사용된다.

객체(object)란?
   자료를 저장하고 처리하는 데이터의 기본 단위이다.
   추상화하여 상태와 행위를 가지는 것 그것을 구체화 한 것이 객체다.
   자바스크립트는 객체 기반의 스크립트 언어이며, 자바스크립트를 이루고 있는 모든 것이라고 해도 무방하다
   원시 타입 외에 데이터 타입은 모두 object이다.
   자바스크립트의 객체는 키와 값으로 구성된 속성들의 집합이다

   - 키(key) : 집합에서 특정한 값을 찾기 위해 다른 값들과 비교되는 값
   - 프로퍼티(Property): 키로 이름을 구별하고 해당 키 값으로 구성되어 있다 (키와 값 한 쌍)
   
   
   
추상화(Abstraction)란?
   - 객체의 공통적인 특성을 추출하여 프로토타입 또는 클래스로 정의한 것.

객체화(instance)란?
   - 추상적인 개념을 구체화시키는 작업.

생성자(constructor)
   new 뒤에 나오는 생성자를 자바스크립트에서는 프로토타입이라고 부른다.
   또는 클래스 이름 뒤에 소괄호가 있는 형태, 메소드와 기능이 똑같지만 메소드라고 부르지 않는다.
   생성자는 리턴이라는 기능이 존재하지 않기 때문이다.

new 연산자
   해당 객체의 필드를 메모리에 할당한 후 부여된 주소값을 가져온다.
   
this 변수
   필드에 접근한 객체가 누구인지 알아야 해당 필드에 접근할 수 있다.
   이 때 접근한 객체가 가지고 있는 할당된 필드의 주소값을 this라는 변수에 자동으로 담긴다.
